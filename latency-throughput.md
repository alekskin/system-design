# Latency and Throughput

## Latency

Essentially, is a time it takes data to reach system.

- Network latency -- time for data to reach the server and get back to user
    - Example: California -> Netherlands -> California packet -- 150ms
    - Memory latency:
        - reading from SSD x5 times slower that from memory.
        - Network is x10 slower than disk
        - HDD is x2 slower than 1Gbps network channel

## Throughput

How much work service can do in a given amount of time.

- Expressed as KB/MB/GB per second, requests per second, queries per second and etc.
- Used as a metric of a system (or a part of the system) performance.
